Freemind theme inspirations

These are Freemind adaptations of the following open-source palettes. Native
app surfaces, simplified syntax rules, and some terminal/light colors are
adapted for contrast. Dracula Light is a Freemind variation; Catppuccin uses
Latte and Mocha as its light/dark references. Theme selections do not install
VS Code extensions.
